# 🔧 Tech Talkies — Maker Projects & Source Code

Welcome to the official repository for **[Tech Talkies](https://www.youtube.com/@techtalkies1)**, a channel exploring electronics, embedded systems, maker hardware, and creative technology.

This repository contains the source code, project files, configuration examples, and documentation for projects featured on the channel. From ESP32-powered gadgets and interactive displays to robotics, AI-enabled hardware, and experimental maker builds, the goal is to explore what's possible with accessible technology.

## 📁 Repository Structure

Each project lives in its own folder, typically containing:

- Source code and firmware
- Hardware requirements and pinout information
- Wiring diagrams and connection tables, where applicable
- Build instructions and configuration notes
- Library dependencies and external references
- A project-specific `README.md` with setup instructions

The contents vary by project and platform.

## 🛠️ Technologies & Topics

Projects in this repository explore a range of hardware and software, including:

- **Microcontrollers:** ESP32, ESP32-S3, ESP32-C3, Arduino, Raspberry Pi Pico, and Seeed Studio XIAO boards
- **Displays & Interfaces:** SPI TFTs, OLEDs, ePaper, touchscreens, LVGL, and custom GUIs
- **AI & Edge Computing:** Embedded AI, vision modules, TinyML, offline experiments, and AI-enabled maker hardware
- **Robotics & Motion:** Servo mechanisms, motor drivers, mobile robots, and interactive physical builds
- **Sensors & Connectivity:** I²C and SPI peripherals, environmental sensors, BLE, Wi-Fi, and web-based device control
- **Creative Electronics:** LED animations, retro-inspired gadgets, handheld devices, wearables, and experimental interfaces
- **Embedded Development:** Arduino IDE, ESP-IDF, PlatformIO, MicroPython, Python, and other tools as projects require

This is an evolving collection. The technologies used depend on the requirements of each build, rather than a single board, framework, or development environment.
